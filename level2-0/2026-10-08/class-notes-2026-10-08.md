# Thai Class — 8 Oct 2026

## Class notes

### Grammar: "also / too"

**ก็ (máay tày khúu) + verb + เหมือนกัน**

| Thai | Meaning |
|---|---|
| ผม หิว lɛ́ɛw | I'm hungry already |
| ฉัน ก็ หิว lɛ́ɛw เหมือนกัน | I'm hungry too |

### Tone contrast

| Word | Meaning |
|---|---|
| mày | new |
| mây | negates a verb (not) |
| máy | question particle |

### Vocabulary

| Thai | Meaning |
|---|---|
| ถูก | correct |
| ผิด | wrong |
| khâaw thîaŋ = khâaw กลางวัน | lunch |
| ʔaahǎan thîaŋ = ʔaahǎan กลางวัน | lunch (food) |
| ทะเล | sea |
| ทะเลสาบ | lake |
| mɛ̂ɛnáam | river |
| thammáchâat | nature |

### Example sentences

- thəə yàak dây sʉ̂a Chanel. — *She wants a Chanel top.*
- raw pay sʉ́ʉ กัน máy — *Shall we go buy it?*
- ตอน níi mây แพง — *It's not expensive now.*
